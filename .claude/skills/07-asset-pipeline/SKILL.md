# Game Asset Pipeline

## 이미지 추가 절차
1. 필요한 에셋 목록을 먼저 만든다.
2. 파일명 규칙을 기존 프로젝트에 맞춘다.
3. 실제 파일 경로를 확인한다.
4. 코드의 참조 경로를 확인한다.
5. 이미지가 로드되는지 확인한다.
6. 누락 에셋과 중복 에셋을 검사한다.
7. 필요하면 로딩 실패 fallback을 확인한다.

## 주의
- 임의로 기존 에셋을 삭제하지 않는다.
- 파일명만 바꾸고 참조를 놓치지 않는다.
- 이미지가 존재한다고 가정하지 말고 실제 파일을 확인한다.
- 저작권 문제가 있는 원본 이미지를 임의로 프로젝트에 포함하지 않는다.
