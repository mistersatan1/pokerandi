# Web Game Testing

## 우선 테스트
1. 게임 시작
2. 유닛 소환
3. 유닛 배치/이동
4. 공격 및 타겟팅
5. 조합/진화
6. 시너지 적용
7. 라운드 진행
8. 보스 전투
9. 보상 및 경제
10. 저장/불러오기
11. 새로고침 후 상태 유지
12. 잘못된 입력/빈 상태

## 회귀 테스트
새 기능이 기존 기능에 영향을 줄 가능성이 있으면 관련 흐름을 함께 테스트한다.

## 결과 보고
- PASS
- FAIL
- NOT TESTED

세 상태를 구분한다. 실제로 실행하지 않은 테스트를 PASS라고 쓰지 않는다.
