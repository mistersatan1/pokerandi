# 포켓몬 랜덤 디펜스 — 간단 설명서

게임 안에서도 오른쪽 위 **?** 버튼이나 **H** 키로 같은 내용을 볼 수 있습니다.

---

## 1. 단축키

| 키 | 동작 |
|---|---|
| **Space** | 소환 |
| **W** | 사거리 강화 — 필드에서 고른 포켓몬의 사거리 +8%/회(최대 5회). 구석 자리 포켓몬을 살린다 |
| **G** | 골드 상점 — 타입별 · 등급별 공격력 (판 전체) |
| **E** | 정예 소환 — 잡으면 골드 + 포켓몬, 놓치면 벌칙 |
| **S** | 창고로 — 필드에서 고른 포켓몬 |
| **F** | 필드로 — 보유 창에서 고른 포켓몬을 빈 칸에 |
| **X** / **Delete** | 방출 — 고른 칸, 없으면 보유 창의 창고 개체 |
| **C** | 조합 — 지금 만들 수 있는 것 중 가장 높은 등급 |
| **1 · 2 · 3** | 게임 속도 |
| **P** | 일시정지 · 이어하기 |
| **R** | 조합 사전 — 모든 조합식 · 흔함 환산 · 검색 |
| **Enter** | 주문 입력 — 숨겨진 조합(히든 · 불멸 · 초월) |
| **H** | 설명서 열기 · 닫기 |
| **Esc** | 선택 해제 · 열린 창 닫기 |

버튼이 잠겨 있을 때(골드 부족 등)는 키를 눌러도 아무 일도 없습니다.

### 마우스

- **필드 칸 클릭** — 그 포켓몬의 정보. 잠긴 칸은 한 번 더 누르면 골드로 삽니다.
- **필드 → 필드 끌기** — 자리 옮기기. 누가 있으면 맞바꿉니다.
- **보유 칸(창고) → 필드 끌기** — 창고에서 꺼내 배치. 찬 칸이면 맞바꿉니다.
- **필드 → 보유 패널 끌기** — 창고로 보냅니다.
- **조합식의 포켓몬 그림 클릭** — 그 포켓몬을 만드는 법. 재료를 누르면 한 단계씩 내려갑니다.
- **보유 칸 클릭** — 필드에 배치 · 방출 · 들어가는 조합식.

---

## 2. 조각 상점

### 조각(◆)이란

원하는 포켓몬을 **골라서** 사는 화폐입니다. 소환은 무작위지만 조각은 콕 집어 삽니다.
조합식에 재료가 딱 하나 모자랄 때 쓰는 **구제책**입니다.

### 얻는 법

| 방법 | 받는 양 |
|---|---|
| 포켓몬 방출 | 흔함 1 · 안흔함 2 · 특별함 3 · 희귀함 5 · 전설 8 |
| 보스 보상 | 받을 자리(필드·창고)가 없으면 그 값만큼 조각으로 대신 받습니다 |

### 여는 법

아래 조합식 패널의 **[◆ 조각 상점]** 탭. 가진 조각은 소환 버튼 아래 **◆ 조각** 에 보입니다.

### 가격

| 등급 | 조각 |
|---|---|
| 흔함 | 5 |
| 안흔함 | 10 |
| 특별함 | 25 |
| 희귀함 | 245 — 25라운드부터 |
| 전설 | 550 — 33라운드부터 |

### 목록 보는 법

- **초록 테두리 · "조합에 바로 필요"** — 이것 하나만 사면 조합식이 완성됩니다. 가장 먼저 볼 것.
- **"곧 필요"** — 재료가 둘 모자란 조합식의 재료.
- 회색 줄은 지금 못 삽니다. 이유가 오른쪽에 적혀 있습니다(25라운드부터 · 조각 부족 · 자리 없음).
- 산 포켓몬은 필드 빈 칸에, 없으면 창고로 갑니다.

### 요령

- 안흔함은 **같은 흔함 2마리**로 만듭니다. 흔함 한 마리가 모자라면 5조각이면 됩니다.
- 남는 흔함을 바로 방출하기보다, 두 마리가 되면 안흔함이 되는지 먼저 확인하세요.
- 쓸 데 없는 포켓몬을 방출해 조각으로 바꾸면 창고 자리도 비고 재료도 삽니다.

---

## 3. 숨겨진 조합 (히든 · 불멸 · 초월)

조합식 목록에는 나오지 않습니다. 재료를 필드나 창고에 모아 두고 **Enter** 로 입력줄을 열어 **주문**을 외치면 만들어집니다.

| 종류 | 조건 |
|---|---|
| 히든 🔒 | 정해진 재료. 강함은 제각각입니다 — 흔함 4마리로 만드는 안흔함부터 전설까지 |
| 불멸 | 전설 3마리 — 파이어 · 썬더 · 프리져 · 뮤츠 · 뮤. 여러 번 만들 수 있습니다 |
| 초월 | 전설 이상 + **초월의 조각**(40라운드 보스 보상) — 한 판에 하나 |

- 히든 포켓몬은 소환·조각 상점·보스 보상으로는 나오지 않지만, **일반 조합식의 재료로는 자주 쓰입니다**.
  조합식에서 🔒 가 붙은 재료, 필드에서 칸 모서리에 **H** 가 붙은 포켓몬이 히든입니다.
- 주문이 맞는데 재료가 모자라면 "…아직 때가 아니다" 가 뜹니다. 틀린 주문은 아무 일도 없습니다.
- 한 번 성공한 주문은 조합 사전(R)의 **🔒 히든** 칸에 재료와 주문이 기록됩니다.
- 첫 주문의 힌트: 스타팅 셋에 캐터피 한 마리를 더해, 트레이너의 가장 유명한 한마디를 외쳐 보세요.
