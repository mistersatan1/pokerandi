# 배경음악 파일

여기에 곡 파일을 넣으면 그 장면에서 합성 음악 대신 반복 재생된다. 없으면 합성 음악 그대로.

| 파일 | 장면 |
|---|---|
| `calm.mp3` | 판 시작 전 · 결과 화면(평시) |
| `battle.mp3` | 라운드 전투 |
| `boss.mp3` | 보스가 나왔을 때 |
| `hidden.mp3` | 히든 주문 연출 |
| `immortal.mp3` | 불멸 주문 연출 |
| `transcend.mp3` | 초월 주문 연출 |

- 경로 · 곡별 음량(0~1) · 겹쳐 넘어가는 시간은 `js/data/music.js` 에서 바꾼다. 다른 이름이나 `.ogg` · `.m4a` 도 된다.
- 곡끼리 크기가 다르면 `volume` 으로 맞춘다. 설정 창의 배경음 음량 · 음소거는 그 위에 곱해진다.
- 반복이 자연스럽게 이어지도록 곡 끝과 처음이 맞물리게 자른 파일이 좋다.
- 한 파일짜리 테스트판(`npm run build`)에는 들어가지 않는다 — 테스트판은 합성 음악.
- 오프라인 저장(홈 화면 앱)에는 아직 넣지 않는다 — 곡이 크면 휴대폰 데이터를 많이 쓰므로.
