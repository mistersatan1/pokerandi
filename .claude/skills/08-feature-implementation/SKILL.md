# Feature Implementation

## 시작 전
- 사용자의 요구사항을 기능 단위로 분해한다.
- 기존 관련 파일을 읽는다.
- 현재 구현 상태를 확인한다.
- 수정 범위를 정한다.

## 구현
- 기존 데이터 구조를 최대한 재사용한다.
- 새로운 전역 상태를 만들기 전에 기존 상태 구조를 확인한다.
- UI와 게임 로직을 가능하면 분리한다.
- 하드코딩된 값을 새로 만들기 전에 기존 상수를 찾는다.
- 저장 데이터에 영향을 주면 버전/마이그레이션을 검토한다.

## 완료 조건
기능이 코드에 들어간 것만으로 완료라고 하지 않는다.
반드시:
1. 동작 확인
2. 관련 기존 기능 확인
3. 콘솔 오류 확인
4. 변경 파일 요약

을 수행한다.
