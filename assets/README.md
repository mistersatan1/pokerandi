# assets

여기에 이미지를 넣으면 게임이 자동으로 사용한다. 비어 있어도 게임은 정상 동작한다.

| 폴더 | 파일명 규칙 | 권장 크기 |
|---|---|---|
| `pokemon/` | 포켓몬 id (`pikachu.png`) | 96×96 PNG, 투명 배경 |
| `enemies/` | 적 id (`swift_01.png`) | 64×64 PNG, 투명 배경 |
| `ui/` | 자유 | — |

픽셀 아트를 쓸 경우 렌더러가 `imageSmoothingEnabled = false` 로 그리므로 도트가 뭉개지지 않는다.
