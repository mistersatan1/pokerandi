# Frontend Design — 포랜디

## 목적
포랜디의 브라우저 UI를 일반적인 AI 생성 웹사이트처럼 보이지 않게 하고 실제 게임 화면처럼 명확한 위계와 개성을 갖도록 한다.

## 핵심 원칙
- 게임판이 항상 가장 중요한 시각적 영역이다.
- 메뉴와 카드가 전투 화면을 압도하지 않게 한다.
- 디자인보다 게임성, 가독성, 정보 전달을 우선한다.
- 모든 요소를 둥근 카드로 감싸거나 보라색 그라데이션/glassmorphism을 남용하지 않는다.
- 의미 없는 장식과 그림자를 줄인다.
- 기존 HTML/CSS/JS 구조를 먼저 조사하고 최소한으로 수정한다.

## 정보 우선순위
최우선: 현재 라운드, 전투 상황, 보스, 방금 획득/완성한 유닛.
중간: 재화, 시너지, 조합식, 유닛 상태.
낮음: 설정, 부가 통계.

## 리디자인 절차
1. 현재 화면과 DOM 구조를 파악한다.
2. UI 영역과 정보 우선순위를 분류한다.
3. 디자인 방향을 제안한다.
4. 작은 영역부터 적용한다.
5. 기능 회귀 테스트를 한다.
6. 전체 화면의 일관성을 점검한다.

## 색상/타이포그래피
- 색상에는 의미를 부여한다.
- 색상만으로 정보를 전달하지 않는다.
- 핵심 숫자는 충분히 크게 표시한다.
- 장식용 폰트보다 가독성을 우선한다.

## 반응형
창 크기가 달라져도 핵심 전투 영역이 깨지지 않게 한다. 패널이 좁아지면 정보 우선순위에 따라 축약한다.

## 절대 원칙
UI 리디자인은 기능 삭제가 아니다. 게임 로직, 저장 데이터, 이벤트 연결을 보존하면서 표현을 개선한다.
