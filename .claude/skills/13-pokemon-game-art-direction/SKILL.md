# Pokémon Game Art Direction — 포랜디

## 게임 정체성
포랜디는 포켓몬 도감 앱이 아니라:
소환 → 발견 → 조합 → 성장 → 시너지 → 전투 → 보상 → 다음 라운드
를 반복하는 랜덤 디펜스 게임이다.

모든 디자인은 이 순환을 강화해야 한다.

## 시각적 목표
화면을 보는 순간:
1. 지금 전투 중이다.
2. 조합하거나 성장시킬 수 있다.
3. 더 좋은 포켓몬을 얻고 싶다.
라는 느낌이 전달되어야 한다.

## 피해야 할 것
- 전형적인 SaaS 카드 UI
- 보라색 그라데이션 중심 디자인
- glassmorphism 남용
- 모든 영역을 카드로 분리
- 장식 과잉
- 모든 버튼의 지속적인 애니메이션
- 계속 움직이는 배경
- 과도한 glow/파티클

강한 효과는 보상으로 남겨둔다.

## 시각적 언어
전투: 명확한 공간, 유닛/적 대비, 짧은 공격/피격 피드백.
조합: 재료 강조 → 연결 → 결과 등장.
시너지: 숫자 목록보다 연결되고 강화되는 구조처럼 보이게 한다.
도감: 단순 목록이 아니라 장기 성장 시스템처럼 느껴지게 한다.

## T1~T5
T1은 단순하고 빠르게, T2는 약간 강조, T3는 눈에 띄게, T4는 특별한 존재감과 스킬 강조, T5는 일반 유닛과 확실히 다른 등장 경험을 준다. 단, 긴 연출은 피한다.

## 라운드
10라운드 단위 보스는 일반 라운드와 다른 시각적 문법을 사용할 수 있다. 경고, 보스 이름, 필드 분위기, 체력 UI 등을 활용하되 반복적인 과잉 연출은 피한다.

## 신규 콘텐츠 판단
1. 기존 포랜디와 같은 게임처럼 보이는가?
2. 기존 등급 체계를 혼란스럽게 하지 않는가?
3. 전투에서 중요한 것이 더 잘 보이는가?
4. 행동에 즉각적인 피드백을 주는가?
5. 시각적 피로를 만들지 않는가?

## 에셋
기존 스프라이트 크기, 비율, 투명 배경, 시각적 밀도를 먼저 확인한다. 새 에셋이 기존 게임과 어울리는지 확인한다.

## 최우선
포랜디는 '예쁜 웹페이지'가 아니라 '계속 플레이하고 싶은 게임'이어야 한다.
가독성 → 피드백 → 게임성 → 일관성 → 장식 순으로 우선한다.
