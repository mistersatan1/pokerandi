# Game Balance

## 검토 항목
- 초반 성장 속도
- 중반 파워 스파이크
- 후반 성장 한계
- 골드 수급과 소비
- 소환 비용과 기대값
- 조합식 재료 수급
- 등급별 출현 확률
- 시너지의 실제 전투 기여도
- 보스 체력/공격력/기믹
- 특정 조합의 과도한 우세

## 변경 원칙
수치를 바꾸기 전에 현재값과 목표값을 비교한다.

가능하면:
- 평균값
- 최악의 경우
- 최선의 경우
- 플레이어가 체감할 구간

을 구분한다.

한 번에 여러 핵심 수치를 크게 변경하지 않는다. 변경 후 예상되는 플레이 흐름을 설명하고 테스트한다.
