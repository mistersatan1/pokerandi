# Game Development Workflow

## 목적
기능을 바로 코딩하지 말고 기존 구조를 먼저 파악한 뒤 계획 → 구현 → 테스트 → 검증 순서로 진행한다.

## 작업 절차
1. 현재 프로젝트 구조와 관련 파일을 먼저 확인한다.
2. 기존 기능과 데이터 구조를 파악한다.
3. 변경 범위를 최소 단위로 정리한다.
4. 구현 전에 필요한 수정 파일과 이유를 간단히 계획한다.
5. 기존 기능을 깨뜨리지 않는 방향으로 구현한다.
6. 가능한 테스트/자체검사를 실행한다.
7. 오류가 있으면 원인을 확인한 뒤 수정한다.
8. 최종적으로 변경 사항과 검증 결과를 요약한다.

## 금지
- 관련 파일을 읽지 않고 코드를 추측해서 수정하지 않는다.
- 같은 문제를 해결하기 위해 불필요하게 구조를 전면 개편하지 않는다.
- 테스트 없이 "완료"라고 판단하지 않는다.
- 사용자가 요구하지 않은 기능을 임의로 추가하지 않는다.
